# React CRUD User Management App

Simple React based CRUD application to manage users.

## Features

- Create, Read, Update, Delete users
- Fields: First Name, Last Name, Phone, Email
- Required field validation
- Toast notifications
- Delete confirmation modal
- Schema driven form (easy to add new fields)
- Scrollable user list
- Clean Bootstrap UI

## Tech Stack

- React (Vite)
- Axios
- Bootstrap
- React Toastify
- JSON Server (mock API)
