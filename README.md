# React CRUD User Management App

A simple React based CRUD (Create, Read, Update, Delete) application to manage user data.

This project was created as a test task to demonstrate React fundamentals, API integration, extensible form architecture, and clean UI design.

---

## Features

- Create new users
- View user list
- Edit existing users
- Delete users with confirmation popup
- Fields:
  - First Name
  - Last Name
  - Phone Number
  - Email Address
- Required field validation
- Toast notifications for user actions
- Scrollable user list
- Clean Bootstrap UI
- Schema driven form (easy to extend)

---

##  Tech Stack

- React (Vite)
- Axios
- Bootstrap
- React Toastify
- JSON Server (mock API)

---

##  Local Setup Instructions

### 1. Clone repository

```bash
git clone https://github.com/skansar9731/react-crud-app.git
cd crud-app

```
### 2. Install dependencies

```bash
npm install

```
### 3. Start Mock API (JSON Server)

```bash
npm run server
API will run on:
http://localhost:3001/users

```
### 4. Start Mock API (JSON Server)

```bash
Open new terminal:
npm run dev
Frontend runs on:
http://localhost:5173

```
