# React CRUD User Management App

A simple React based CRUD (Create, Read, Update, Delete) application to manage user data.

This project was created as a test task to demonstrate React fundamentals, API integration, extensible form architecture, and clean UI design.

---

## Features

- Create new users
- View user list
- Edit existing users
- Delete users with confirmation popup
- Fields:
  - First Name
  - Last Name
  - Phone Number
  - Email Address
- Required field validation
- Toast notifications for user actions
- Scrollable user list
- Clean Bootstrap UI
- Schema driven form (easy to extend)

---

##  Tech Stack

- React (Vite)
- Axios
- Bootstrap
- React Toastify
- JSON Server (mock API)
